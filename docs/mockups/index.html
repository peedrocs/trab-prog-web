Telas planejadas

Mockups das páginas do sistema, feitos em HTML e CSS puros com a mesma folha de estilo do site. Os dados são de exemplo.

Loja

  • Catálogo: busca, filtro por categoria e cartões dos produtos
  • Produto: detalhes e botão de adicionar ao carrinho
  • Carrinho: itens, quantidades e resumo do total
  • Entrar: formulário de login
  • Criar conta: formulário de cadastro com mensagens de erro
  • Meus pedidos: histórico do cliente com o status de cada pedido

Administração

  • Painel: números da loja e menu da administração
  • Pedidos: todos os pedidos, com a troca de status

Fluxo de CRUD de produtos

  1. Listagem: tabela com Editar e Excluir em cada linha
  2. Cadastro: formulário em branco
  3. Edição: o mesmo formulário já preenchido
  4. Exclusão: página de confirmação
